# Markdown 文档导出（纯 H5/JS 版）

在浏览器本地把 Markdown 转换为 Word（.docx）或 PDF。不依赖 Vue 和构建工具，内容只在当前浏览器中处理。

## 使用方法

1. 双击 `index.html` 在浏览器中打开。
2. 在左侧编辑 Markdown，右侧实时预览 A4 版式。
3. 点击「导入 MD」载入 `.md` 文件。
4. 文档里引用了本地图片时，点击「添加图片」选择对应图片文件，文件名需与 Markdown 中的路径一致。
5. 点击「导出 Word」或「导出 PDF」，文件保存到浏览器的下载目录。

如果用 `file://` 打开后图片加载或导出异常，可以在本目录启动静态服务：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 目录结构

| 文件         | 说明                                                       |
| ------------ | ---------------------------------------------------------- |
| `index.html` | 页面结构，用 `<script>` 标签加载各库                       |
| `app.js`     | 全部业务逻辑：Markdown 渲染、Word 导出、PDF 导出、页面交互 |
| `style.css`  | 页面与预览样式                                             |
| `libs/`      | 第三方库的浏览器版本，支持离线使用                         |

## 依赖库

| 库                 | 用途                    |
| ------------------ | ----------------------- |
| marked 9.1.6       | 解析 Markdown           |
| DOMPurify 3.5.0    | 清理预览 HTML，防止 XSS |
| docx 9.16.0        | 生成 .docx 文件         |
| html2pdf.js 0.14.0 | 生成 PDF                |

## 功能说明

- 支持标题、段落、粗体、斜体、删除线、行内代码、链接、图片、列表（含任务列表）、引用、表格、代码块和分割线。
- 在 Markdown 中写 `<!-- pagebreak -->` 可插入分页符。
- Word 导出为 A4 版式，页脚带页码。
- 图片可以是 `http(s)`、`data:` 地址，或通过「添加图片」上传的本地文件。

## 说明

- `app.js` 由原 Vite 项目（`../MD格式转word`）的 `src/*.js` 合并生成。后续改功能直接编辑 `app.js` 即可。
- 修改样式编辑 `style.css`。
